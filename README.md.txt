# Student Performance Prediction Using Machine Learning

## 1. Project Description
This project predicts whether a student will pass or fail based on study hours, attendance percentage, and previous examination marks.

## 2. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 3. Machine Learning Algorithm
Decision Tree Classifier

## 4. Input Features
- Study Hours
- Attendance Percentage
- Previous Marks

## 5. Output
The model predicts whether a student is likely to PASS or FAIL.

## 6. Project Files
- Predictive_Modeling.ipynb — Contains the Python code and model evaluation.
- student_performance_model.pkl — Stores the trained machine learning model.
- README.txt — Contains the project description and details.

## 7. How It Works
1. Create the student dataset.
2. Separate input features and target output.
3. Split the data into training and testing sets.
4. Train the Decision Tree Classifier.
5. Predict student results.
6. Evaluate the model using accuracy and a confusion matrix.
7. Enter new student details to predict PASS or FAIL.

## 8. Note
This project uses a small sample dataset for demonstration. Predictions are not guaranteed to represent real-world student performance.
